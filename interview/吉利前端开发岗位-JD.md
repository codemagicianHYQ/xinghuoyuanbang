# 吉利汽车 · 前端开发工程师 招聘说明（JD）

## 一、岗位名称与部门

**岗位名称**：前端开发工程师 / Web 前端开发  
**所属部门**：数字化 / 智能网联 / 信息技术（以实际招聘为准）  
**工作地点**：杭州 / 宁波 / 上海等（以实际为准）  
**招聘类型**：校园招聘 / 社会招聘 / 实习

---

## 二、岗位职责

1. 参与公司**内部管理系统、运营平台、营销活动页**等 Web 前端项目的开发与维护，保障产品体验与稳定性。
2. 与产品、设计、后端协作，完成**需求评审、接口联调、前后端分离**下的功能开发与上线。
3. 负责前端**组件化、模块化**设计与实现，参与公共组件库或业务组件沉淀，提升团队开发效率。
4. 参与**小程序 / H5 / 多端**项目开发（如活动页、用户端功能），配合业务实现跨端或响应式适配。
5. 关注**性能优化、兼容性与可访问性**，参与代码评审与技术方案讨论，推动前端工程化与规范落地。

_（若岗位涉及车机 / HMI：参与车载人机交互界面的前端开发或与车机团队协作对接。）_

---

## 三、任职要求

### 必备条件

- **学历**：本科及以上，计算机、软件工程、电子信息等相关专业优先。
- **前端基础**：熟练掌握 **HTML5、CSS3、JavaScript（ES6+）**，能独立完成复杂页面布局与交互实现；熟悉 **Vue.js**（Vue 2 / Vue 3）或 React 其一，具备**组件化、模块化**开发经验。
- **工程能力**：熟悉 **Vite、Webpack** 等前端构建工具；熟练使用 **Git** 进行版本控制与协作；熟悉 **npm / pnpm** 等包管理。
- **协作与学习**：具备良好的沟通与文档习惯，能快速理解业务需求；有较强的学习与问题排查能力，能独立解决常见前端问题。

### 优先考虑

- 有 **uni-app / 小程序** 或跨端开发经验，有实际项目上线与维护经历。
- 熟悉 **Vuex / Pinia、Vue Router**，能设计并实现中后台、SPA 类项目的前端架构与状态管理。
- 了解或使用过 **Node.js、Express**，能阅读或编写简单后端接口，具备**前后端分离、RESTful API** 联调经验。
- 有 **Nginx 配置、Linux 部署、HTTPS/SSL** 等部署与运维相关经验，能独立完成前后端分离项目的部署与排错。
- 有 **数据可视化、大屏、移动端 H5** 或**车机 / 智能座舱**相关项目经验者优先。

## 五、加分项（面试可主动提及）

- 有**完整项目**从需求到上线的经历（如星火园帮：小程序 + 管理后台 + Node 后端 + Nginx 部署）。
- 能说清**前后端分离**下的请求链路、鉴权（JWT）、错误处理与部署方式。
- 有**性能优化、首屏优化、分包、接口合并**等实践。
- 有**组件抽象、状态管理设计、路由与权限**等架构层面的思考。
- 有**独立排查线上问题**（如跨域、502、证书、移动端兼容）的经验。

## 六、面试时如何用这份 JD

1. **自我介绍 / 为什么投我们**：结合 JD 中的「岗位职责」和「优先考虑」，挑 2～3 条与星火园帮经历对应（如：做过管理后台与小程序、有 Node 与 Nginx 部署经验）。
2. **项目深挖**：按 JD 里的技术栈准备「用 Vue 做了什么」「如何做鉴权与权限」「如何部署」等，对应《吉利前端面试-基于简历与星火园帮》中的题目。
3. **短板补充**：若 JD 提到 React、车机、大屏等而你经验较少，可诚实说「目前以 Vue 为主，有扎实前端基础，愿意在入职后快速学习」。
