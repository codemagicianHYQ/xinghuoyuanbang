## 吉利前端开发一面题目（基于你的简历与星火园帮项目，仅题目版）

> 说明：下面这些题目是站在「吉利汽车前端开发一面面试官」视角，为你的简历和「星火园帮」项目量身定制的一套题目清单，仅保留题干，方便你自测与模拟面试。详细参考答案可在 `吉利前端面试-基于简历与星火园帮.md` 和 `前端面试-基础概念解析.md` 中找到对应内容。

## 一、项目 & 业务理解

1. 请你用 2 分钟介绍一下「星火园帮」这个项目：面向哪类用户、解决什么问题、目前的使用情况如何？
2. 星火园帮中你个人负责的核心模块有哪些？请按优先级说出 2–3 个，并简单说明你在其中具体做了什么。
3. 如果把星火园帮迁移到「校园后勤/车主服务场景」下，哪些模块可以直接复用？哪些需要重新设计？你会如何做需求拆分与技术选型？
4. 星火园帮从 2 月做到 6 月，整个过程中你遇到的最大技术难点是什么？你是怎么定位问题并一步步解决的？
5. 在星火园帮的开发中，有没有出现「线上 bug / 线上性能问题」？请任选一个具体例子，用 STAR（情景-任务-行动-结果）方式讲一讲。

## 二、Vue / uni-app / 小程序

6. 你的小程序端使用的是 uni-app + Vue2，请你从「开发体验」「多端适配」「性能」三个角度，说说 uni-app 相比原生小程序的优缺点。
7. 如果让你现在在 uni-app 项目里增加一个「订单实时状态刷新」功能，你是更倾向于轮询还是 WebSocket？为什么？请简要设计一下前端大致代码结构。
8. 结合星火园帮项目，谈谈你在实际开发中对 Vue2 和 Vue3 的理解差异：从响应式实现、组合式 API、生命周期和模板能力几个角度各举一条。
9. 在 Vue2 中对象新增一个字段默认是不是响应式？如果不是，你会用什么方式让它变成响应式？在项目里你遇到过类似问题吗？
10. 请你设计一个「任务卡片」组件，既要在小程序端使用，也要在管理后台（Vue3 + Element Plus）中使用，如何拆分组件和抽离复用逻辑？
11. 说说你在项目里常用的几种「组件间通信方式」，并分别给出与星火园帮有关的具体使用场景。
12. 结合星火园帮的实际业务，阐述一下你如何使用 Vue Router 组织前端路由（包含：路由模式选择、路由懒加载、权限控制/导航守卫）。
13. 在不改变体验的前提下，你会如何优化「小程序首屏加载速度」和「管理后台首屏白屏时间」？

## 三、JavaScript / ES6+ / 浏览器基础

14. 请比较 `var / let / const` 的差异，并结合你在项目里踩过的坑，说一说为什么实际开发更推荐 `let / const`。
15. 假设面试官问你「如何自己实现一个类似 const 的机制」，你会如何回答？可以从语言层面约束和 JS 代码层模拟两个角度简要说明。
16. 解释一下闭包（Closure），并用你在防抖/节流或请求封装里的真实代码场景来说明闭包是如何发挥作用的。
17. 介绍一下 ES6 相对 ES5 的几项你最常用、对实际开发帮助最大的特性，并尽量结合星火园帮的代码例子来回答。
18. 讲讲你常用的几种数组方法（map、forEach、filter、reduce 等），以及在什么情况下更适合用 map 而不是 forEach。
19. 解释一下 JavaScript 中的原型和原型链，用你熟悉的方式画或口述一条简单的原型链结构。
20. 说说箭头函数和普通函数在 `this`、arguments、构造函数能力等方面的区别，在什么场景你会坚决不用箭头函数？
21. 结合事件循环，解释一下什么是宏任务、微任务，并根据你写过的 Promise / async 函数举一个「输出顺序容易被问」的例子。
22. 假设面试官给你一个「下拉刷新 + 上拉加载更多」的场景，你会如何利用节流/防抖和虚拟列表等手段避免长列表滑动卡顿？

## 四、CSS / 布局 / 视觉实现

23. 请解释 `display: block / inline / inline-block` 的区别，并回答：200px 宽度的父容器中放两个宽度都是 100px 的 `inline-block` 元素，会出现什么布局结果？可能出现什么坑？如何解决？
24. 说说你常用的实现「水平 + 垂直居中」的几种写法（至少三种），并指出它们在兼容性和语义上的差异。
25. 解释一下 CSS 盒模型（Box Model）以及 `box-sizing: border-box` 带来的变化，你在项目里是否统一使用了 `border-box`？
26. 什么是 BFC？请列举 2–3 个你在实际项目中使用 BFC 的场景（例如解决哪些布局问题）。
27. Flex 布局中如何实现「左右两侧对齐」？请给出两种常用写法，并谈谈它们适合用在什么 UI 场景中。
28. 你在项目中有没有遇到过「需要隐藏滚动条但保留滚动」的需求？你是如何通过 CSS 完成的？是否考虑过不同浏览器的处理方式？

## 五、网络 / 接口设计 / 实时通信

29. 结合星火园帮的接口，请你设计一条 RESTful 风格的「任务列表」接口：说明 URL、HTTP 方法、请求参数（query/body）、返回结构。
30. 请解释一下 GET 和 POST 的区别，并说说在你项目里有哪些场景你会明确指定用 PUT 或 DELETE。
31. 谈谈你对 fetch 和 Axios 的理解：从错误处理、拦截器、返回值类型等方面比较，并说明你在项目中选择 Axios 的原因。
32. 什么是同源策略？什么情况下前端会遇到跨域问题？在星火园帮管理后台访问 Node 接口的场景下，你是如何处理跨域/代理的？
33. 用自己的话解释一下 WebSocket 是什么，相比轮询有什么优缺点？如果现在要把小程序的消息提醒从轮询改为 WebSocket，你会如何规划这次改造？
34. 你在项目部署时是否关注过 HTTP/2 或 HTTP/3？说说你目前对它们差异的理解，以及在实际项目中可能带来的收益。
